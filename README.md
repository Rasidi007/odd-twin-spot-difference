Odd Twin is an original spot-the-difference game: four hand-drawn scenes, 29 hidden differences, hints, combos and a timer — playable offline in a desktop browser.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
python3 -m http.server 8080 --directory out/game
```

Then open http://localhost:8080 in desktop Chrome.
